# Key sign-in sheet (OpenRouter, MiniMax)

`PATH=/usr/bin:$PATH CHROME_DEVTOOLS_AXI_SESSION=<task-name> scripts/verify/key-sheet.sh <out-dir>` (done-done journey `key-sheet`; no model call, no vendor, no real key). It boots real crewd and the built UI with the kit on its own fake Gateway (`scripts/verify/key-sheet.ts`), so the pasted stub key goes through the kit's real `addKey` and the model list through its real `models`. At 390 and 1280, day and night, for each account: Home's "Sign in with <account>" opens the key sheet, the stub key is pasted, and the sheet moves on by itself — no list of engine names, no pick to guess past. It says the crew thinks with the account's own model and names it in one line, with **Pick another model** to Settings. `GET /api/accounts/1/<account>/model` must answer `picked: null` (nothing picked by hand) and `dflt` naming the model a run takes: MiniMax's own Flash. OpenRouter's live list carries no default tag, so its line says the crew uses the model the key comes with; that account's pick stays a Settings choice. It fails on a missing step, on a sheet that never names where a key comes from: a `Get a <account> key` button whose target is the vendor's own key page (OpenRouter `openrouter.ai/keys`, MiniMax its console's key page) is required before the paste step, and on a model the server does not report.

Shots (`key-sheet-1-key`, `-2-signed-in`; 16 in all) land in `<out-dir>`. Look at each: no sheet content cut, the stepper reads Get your key / Paste it / Done, the model line fits at 390 beside its link.

Phone app: `PhoneKeySheet` (mobile/App.tsx) lists every `keyEntry` account from `A.AIS` and, once the key is saved, the phone's own live list to pick from. Not driven here; it is the cloud-computer owner's phone path, and the phone keeps its own pick.

OpenRouter's browser sign-in is no longer offered in the app's sheet (the key route replaces it); the API route (`openrouter-signin.md`) is unchanged. The real-key proof of a model run is `chat-real`/`crew-room` with `CREW_ACCOUNT=openrouter`, which spends and needs approval.
