# App icon exports

`node scripts/icons.mjs` draws the committed exports from `web/src/art.ts` with ImageMagick. Chief's artwork and Pocket Pals palette are shared across platforms; small desktop/favicon sizes use his existing simplified face. Native launchers supply their own corners, so the native and store masters have a full opaque background.

| Surface | Assets | Wiring |
| --- | --- | --- |
| Android launcher | `mobile/assets/icon.png` (1024), `android-icon-{foreground,background,monochrome}.{svg,png}` (1024) | `mobile/app.json`: `expo.icon`, `android.adaptiveIcon`; Expo prebuild creates `mobile/android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher{,_round}.webp` at 48/72/96/144/192 and the three adaptive layers at 108/162/216/324/432. `mipmap-anydpi-v26/ic_launcher{,_round}.xml` reference all three layers. Foreground and monochrome fit inside the 66 dp safe circle on the 108 dp canvas. |
| Android notifications | `mobile/assets/notification-icon.png`, `mobile/assets/bubble/glyph.png`, `web/notify.svg`, `web/notify-96.png` | `expo-notifications` config generates `drawable-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/notification_icon.png` at 24/36/48/72/96 and manifest metadata for FCM/local notifications. `mobile/src/chip.ts` supplies `notification_icon` to the status kit. The overlay config registers `chief_glyph`; `mobile/src/bubble.ts` uses it. Both are white on transparent with padding. |
| iOS AppIcon | `mobile/assets/icon.{svg,png}` (1024, RGB without alpha) | `expo.icon` creates `mobile/ios/Crewhouse/Images.xcassets/AppIcon.appiconset/App-Icon-1024x1024@1x.png`. Expo's universal iOS asset catalog uses the 1024 source; Xcode supplies device renditions for the supported iOS 18+ app rather than requiring a legacy size list. |
| Web/favicon | `web/favicon.svg`, `favicon-{16,32,48}.png`, `favicon.ico` (16/32/48 frames), `icon.svg`, `icon-{192,512}.png` | `web/index.html` references SVG, ICO and PNG favicons. `scripts/build-web.mjs` copies them to `web/dist`; `src/server.ts` serves ICO with its image MIME type. README uses `web/icon-192.png`. |
| Apple home screen | `web/apple-touch-icon.png` (180, RGB) | `web/index.html` apple-touch-icon link. |
| PWA | `web/icon-{192,512}.png`, `icon-maskable-{192,512}.png`, `icon-maskable.svg`, `notify-96.png` | `web/manifest.webmanifest` declares regular, maskable and monochrome purposes; `scripts/build-web.mjs` copies the manifest and referenced files. The maskable Chief fits the central 80% safe circle. The SVG maskable file is the raster source. |
| Linux desktop | `packaging/icons/crewhouse-{16,24,32,48,64,128,256,512}.png` | `scripts/package.mjs` installs each into `usr/share/icons/hicolor/<size>x<size>/apps/crewhouse.png`; `packaging/crewhouse.desktop` uses `Icon=crewhouse` and matches the Chromium app window's class. The Chromium window also uses the web favicon. There is no separate native tray or macOS/Windows app package in this repository; `packaging/bar-pill.mjs` supplies text to a desktop bar. |
| Store uploads | `mobile/store/google-play-icon.png` (512), `mobile/store/app-store-icon.png` (1024), RGB | Generated upload assets, with no baked corner mask. Store-console uploads remain a release step. |

Generated `mobile/android` and `mobile/ios` directories are ignored and recreated by Expo prebuild. The obsolete, unused Expo splash placeholder is removed. Office sprites, account marks and Chief's overlay mood images are also generated by this script; they retain their existing artwork.

Task screenshots/contact sheets belong outside the repository and are not release assets.
