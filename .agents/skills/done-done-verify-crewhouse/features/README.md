# crewhouse features

The repo's maintained verification map; a proof that drives one entry point is incomplete when this lists others.

- [Onboard and chat with Chief](onboard-and-chat-with-chief.md): Open the app's first screen (Hello), or call the API directly after a fresh lab starts
- [Recruit a helper and assign it a job](recruit-a-helper-and-assign-it-a-job.md): Send a message to Chief that carries a crew_recruit tool call, then post a job in the new helper's own thread
- [Chief's thread on a desktop and a phone](chief-s-thread-on-a-desktop-and-a-phone.md): Open the app's private launcher URL for the lab, then the Chief thread (#/chief)
- [Onboarding from Hello into Chief's thread](onboarding-from-hello-into-chief-s-threa.md): First run in a fresh browser session shows the Hello screen with three ideas
- [Chief's real reply on MiniMax Flash](chief-s-real-reply-on-minimax-flash.md): Send Chief a message on a computer signed in to MiniMax; his reply shows in his thread
- [Phone live control](phone-live-control.md): Open a working helper's chat on the phone layout; its control bar has Stop and Take control, and an ask shows Yes, go ahead
