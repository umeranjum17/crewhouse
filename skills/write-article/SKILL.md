# Write an article

1. Pin down the one question the reader has and what they mean by searching it. Ask only if the answer would change the article.
2. Look at what already ranks for that question. Note what it answers well and what it leaves out; check primary sources for facts.
3. Bring something genuinely useful that is not already there: first-hand detail, data, or specific examples. Never invent experience or evidence.
4. Outline around the reader's likely questions. Answer the main question first, and start each section with its answer before adding context.
5. Give it a clear title, a concise meta description and a readable URL slug. Cite primary sources for factual claims.
6. Suggest where a screenshot, table or diagram would make the explanation clearer. End with a natural next step for the reader.
7. Save the draft to `files/<slug>.md`. Never publish it.
