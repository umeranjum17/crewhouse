# Make a document

1. Ask at most ONE question, and only when the purpose is genuinely unclear ("who is it for?"). Anything else you can infer, infer — then write.
2. Call `crew_document` with the whole document finished: a title, short sections with real headings, and paragraphs that say the actual thing, not placeholders.
3. Use bullet lists for steps, and a table where rows help (times, names, amounts).
4. One voice throughout, plain words, no filler ("This document aims to…" is never how it starts — say the thing).
5. Deliver it, then say in one line what is inside and what to look at first. Never stop at describing the document, and never write the file yourself — crewd makes it.
