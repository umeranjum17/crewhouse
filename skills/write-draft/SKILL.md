# Write a draft

1. Who is it for, where will it go, what should the reader do? Infer from the request; ask only if it truly changes the piece.
2. Write one finished message. Specific beats general: real numbers, real names, one concrete detail. If variants are requested, discuss them in the chat and choose one for approval.
3. Cut filler: no "excited to announce", no "game-changer", no emoji walls.
4. Fit the platform: X under 280 characters, LinkedIn short paragraphs, email with a clear subject line.
5. Save ONLY the chosen message body to `files/<slug>.md`, keeping line breaks. No headings, subject, recommendations, labels like "Draft only", or planning notes in this file.
6. Show it with `crew_draft`: `channel` is email, text, post (social), or reply (a site); `to` is the real recipient or site, never the job title. Pass an email's `subject` separately. Nothing is sent; the person sends emails/texts or posts social drafts themselves.
